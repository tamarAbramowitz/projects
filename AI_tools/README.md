## 🌐 פרויקטים

### 🍳 ספר המתכונים - אתר מתכונים עם הקראה קולית

**[לצפייה באתר החי לחץ כאן](https://tamarabramowitz.github.io/projects/AI_tools/recipe-website/)**

אתר מתכונים מתקדם עם פונקציית הקראה קולית המאפשר למשתמשים לנהל ולהקריא מתכונים תוך כדי בישול.

#### תכונות עיקריות:
- 🔐 מערכת התחברות עם משתמשים
- 🍽️ ניהול וחיפוש מתכונים
- 🔊 הקראה קולית חכמה של הוראות
- ⚙️ הגדרות אישיות מתקדמות
- 🎨 עיצוב רספונסיבי ונגיש
- 🌐 תמיכה מלאה בעברית

#### טכנולוגיות:
- HTML5, CSS3, JavaScript
- Web Speech API
- Local Storage

[למידע נוסף על הפרויקט](./recipe-website/README.md)
