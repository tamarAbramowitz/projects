# 🍳 ספר המתכונים - אתר מתכונים עם הקראה קולית

🌐 **[לצפייה באתר החי לחץ כאן](https://tamarabramowitz.github.io/projects/AI_tools/recipe-website/)**

## תיאור הפרויקט

אתר מתכונים מתקדם עם פונקציית הקראה קולית המאפשר למשתמשים לנהל ולהקריא מתכונים תוך כדי בישול.

## תכונות עיקריות

### 🔐 מערכת התחברות
- התחברות עם שם משתמש וסיסמה
- 3 משתמשים לדוגמה מוכנים מראש
- שמירת מצב התחברות

### 🍽️ ניהול מתכונים
- רשימת מתכונים עם תמונות
- חיפוש מתכונים לפי שם או רכיבים
- הוספת מתכונים חדשים
- תצוגה מפורטת של כל מתכון

### 🔊 הקראה קולית חכמה
- הקראה קולית של הוראות הכנה
- בקרות עצור/המשך/קודם/הבא
- הדגשת השלב הנוכחי
- גלילה אוטומטית לשלב הנוכחי

### ⚙️ הגדרות אישיות
- מהירות הקראה
- זמן המתנה בין שלבים
- גובה הקול
- ערכת צבעים (בהיר/כהה/אוטומטי)
- גודל טקסט
- ניגודיות גבוהה
- הגדרות תצוגה נוספות

## הוראות הפעלה מקומית

1. הורד את כל הקבצים לתיקיה אחת
2. פתח את הקובץ `index.html` בדפדפן
3. התחבר עם אחד מהמשתמשים לדוגמה
4. התחל להשתמש באתר!

## העלאה לאינטרנט - אפשרויות חינמיות

### 1. GitHub Pages (מומלץ)
```bash
1. צור repository חדש ב-GitHub
2. העלה את כל הקבצים
3. עבור ל-Settings > Pages
4. בחר Source: Deploy from a branch
5. בחר Branch: main
6. האתר יהיה זמין ב: https://username.github.io/repository-name
```

### 2. Netlify
```bash
1. עבור ל-netlify.com
2. גרור את התיקיה לאזור "Deploy"
3. האתר יהיה זמין תוך דקות
```

### 3. Vercel
```bash
1. עבור ל-vercel.com
2. התחבר עם GitHub
3. בחר את ה-repository
4. לחץ Deploy
```

### 4. Firebase Hosting
```bash
1. התקן Firebase CLI: npm install -g firebase-tools
2. firebase login
3. firebase init hosting
4. firebase deploy
```

## פתרון בעיות נפוצות

### הקראה קולית לא עובדת
- ודא שהדפדפן תומך ב-Web Speech API
- בדוק שהקול לא מושתק
- נסה דפדפן אחר

### הנתונים לא נשמרים
- ודא ש-Local Storage מופעל בדפדפן
- נקה cache ונסה שוב
- בדוק שאין מצב פרטי מופעל

### האתר לא נטען
- ודא שכל הקבצים באותה תיקיה
- בדוק שאין שגיאות ב-Console
- נסה לרענן את הדף
